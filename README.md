# 딩기요트 권리정 시뮬레이터

정적 HTML/CSS/JS로 만든 딩기요트 학습 사이트입니다.

## 기능

- 바람 방향 조절
- 보트 A/B 위치 드래그
- 보트 A/B 방향 무제한 회전 입력 및 회전 버튼
- 태킹 중 상태 체크
- 마크 표시, 마크 드래그, 3보트길이 존 표시
- Rule 10~13 기본 상황 권리정 색상 표시
- RRS 조항과 구체적 판정 이유 표시
- 한국어/영어 전환
- 초보자용 딩기요트 기본 용어 그림 설명

## 무료 배포

1. Cloudflare 대시보드에서 `Workers & Pages`를 엽니다.
2. `Create application` → `Pages` → `Drag and drop your files`를 선택합니다.
3. 프로젝트 이름을 `yacht-rules-simulator`처럼 입력합니다.
4. 이 `dinghy-right-of-way-site` 폴더 전체를 업로드합니다.
5. `Deploy site`를 누릅니다.

배포 후 발급되는 `https://프로젝트이름.pages.dev` 주소를 Blogger의 외부 링크 메뉴에 연결하면 됩니다. 호스팅과 HTTPS 비용은 0원입니다.

## 연결된 무료 블로그

- https://yachtrules.blogspot.com/

## 주의

이 도구는 World Sailing Racing Rules of Sailing 2025-2028의 기본 권리정 규칙을 학습용으로 단순화한 것입니다. RRS 18 마크룸은 존과 주의 문구만 제공하며 완전한 마크룸 판정은 하지 않습니다. 실제 경기 판정에는 마크룸, 룸 투 택, 장애물, 룰 16/17, 출발 규칙, 심판 해석 등이 추가로 적용될 수 있습니다.
